Privacy Policy

Last updated: September 18, 2026

Asmodeus respects user privacy and handles data with care:

  • Data Collected: We only store basic Discord identifiers (Server IDs, User IDs, Channel IDs) required for bot functionality.
  • Data Usage: Collected data is strictly used to process bot commands and maintain configuration settings.
  • Data Sharing: No user data is sold, shared, or transferred to third parties.
  • Data Removal: Removing the bot from your server will permanently purge your stored server configuration.
